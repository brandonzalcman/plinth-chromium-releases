# Plinth Chromium

Downloads for Plinth Chromium, the Chromium-based version of [Plinth](https://getplinth.dev). It has the same calm way of browsing as Plinth, and it runs Chrome extensions.

Download the newest disk image from [Releases](https://github.com/brandonzalcman/plinth-chromium-releases/releases/latest). Open it and drag Plinth Chromium to Applications. It's signed and notarized by Apple, and it updates itself.

Plinth Chromium needs macOS 26 or later.

This repository holds only the releases and the update feed. For questions and help, see [getplinth.dev/support](https://getplinth.dev/support.html).
