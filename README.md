This repository holds the signed releases of [Plinth Chromium](https://github.com/brandonzalcman/Plinth-Chromium) and the feed it updates from. The source code, issues and documentation are in [Plinth-Chromium](https://github.com/brandonzalcman/Plinth-Chromium).

## Install

1. Download the newest `Plinth-Chromium-<version>.dmg` from [Releases](https://github.com/brandonzalcman/plinth-chromium-releases/releases/latest).
2. Open it and drag **Plinth Chromium** to **Applications**.
3. Open it from Applications. It's signed and notarized by Apple, so it opens without warnings.

Plinth Chromium checks for updates on its own, or choose **Plinth → Check for Updates**. It needs macOS 26 on an Apple silicon Mac.
